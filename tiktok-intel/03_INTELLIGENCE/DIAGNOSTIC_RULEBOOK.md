# Diagnostic Rulebook

Each rule requires:
ID, version, required data, preconditions, trigger thresholds, counter-evidence, exclusions, confounders, severity, confidence logic, evidence payload, diagnosis, hypothesis, recommendation, don't-touch, monitor plan, success criteria, limitations, golden tests.

Core families:
TRAFFIC, VIEW, ATC, CHECKOUT, CONV, AOV, ADS, GMVMAX, PROD, LIVE, AFF, DATA, ANOM.

No vague threshold language is allowed in production rules.
