# UX Specification

## Primary decision hierarchy
1. Biggest issue
2. Why
3. Evidence
4. Do this first
5. Don't touch yet
6. Monitor
7. Success criteria
8. Supporting data

## Mobile
The first viewport must communicate the primary decision without requiring horizontal tables.

## States
- No data
- Processing
- Validation warning
- Data invalid
- Insufficient evidence
- Healthy
- Problem detected
- Anomaly
- System error

## Accessibility
Target WCAG 2.2 AA.
