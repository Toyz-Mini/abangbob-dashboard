# User Flows

## First analysis
Create account → create workspace → create shop → upload file → scan → detect dataset → map columns → validate → preview → import → choose period → run analysis → review diagnosis → review recommendation → optionally create experiment.

## Repeat analysis
Upload → reuse mapping template → validate → import → compare → diagnose.

## Correction
Import warning → edit mapping → revalidate → replace derived snapshot only for the new analysis.

## Failure
Upload → validation failure → actionable error → correction → retry.
