# Product Requirements Document — V1.2

## Product
TikTok Shop Seller & Marketer Intelligence

## Problem
TikTok Shop data is fragmented across reports and metrics. Sellers and marketers must manually inspect multiple places and mentally connect traffic, funnel, product, ads, GMV Max, LIVE, affiliate and trend data.

## Product promise
Turn fragmented uploaded data into:
- what changed
- what matters
- what is likely wrong
- what to do first
- what not to change yet
- what to monitor
- how to test the recommendation

## MVP scope
- Manual CSV/XLSX upload
- Data mapping and validation
- Normalization
- Historical comparison
- KPI dashboard
- Diagnostic engine
- Recommendation engine
- Analysis snapshots
- Optional AI explanation
- Experiment tracking
- Exportable analysis

## Explicitly out of MVP
- TikTok API integration
- Automatic data ingestion
- Autonomous campaign changes
- Guaranteed outcome claims
- Automated causal inference

## Core loop
DATA → METRICS → OBSERVATION → DIAGNOSIS → HYPOTHESIS → PRIORITY → ACTION → EXPERIMENT → RESULT → LEARNING

## Product principles
1. Decision quality over chart quantity.
2. Evidence before recommendation.
3. Rule engine before AI.
4. No fabricated diagnosis.
5. Distinguish observation, diagnosis and hypothesis.
6. Preserve reproducibility.
7. Show limitations.
