# Requirement Traceability

Every P0/P1 requirement must have a stable ID and complete traceability.

| Field | Required |
|---|---|
| Requirement ID | Yes |
| Requirement text | Yes |
| Priority | Yes |
| Source | Yes |
| Acceptance Criteria ID | Yes |
| Design/Spec ID | Yes |
| Implementation module | Yes |
| Automated Test IDs | Yes |
| Manual/UAT evidence | Where applicable |
| Release version | Yes |
| Status | Yes |

A P0 item cannot be marked DONE without implementation evidence and passing verification.
