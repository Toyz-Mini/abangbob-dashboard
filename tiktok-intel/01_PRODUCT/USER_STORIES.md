# User Stories

## Seller
- As a seller, I want to upload my TikTok reports and see the biggest issue first.
- As a seller, I want to know why the system thinks something is wrong.
- As a seller, I want the system to tell me what not to change yet.
- As a seller, I want to compare current performance with an equivalent period.
- As a seller, I want to save analysis history.

## Marketer
- As a marketer, I want one view across traffic, funnel, products and ads.
- As a marketer, I want deterministic evidence before making budget decisions.
- As a marketer, I want to create experiments from recommendations.
- As a marketer, I want to explain findings to clients.
