# TikTok Shop Intelligence — Design Strategy V1.7

## Design objective

The product is not a generic analytics dashboard.

The interface must help a seller/marketer answer, in order:

1. What changed?
2. Is it important?
3. Why did it likely happen?
4. What should I fix first?
5. What should I NOT touch?
6. How will I know whether the fix worked?

The primary UX goal is **decision velocity**, not maximum chart density.

## Reference systems researched

### Vercel Geist
Use as the strongest reference for:
- restrained visual language
- typography hierarchy
- high-contrast accessible color system
- compact, composable components
- grid discipline
- professional developer/SaaS feel

Vercel describes Geist as its design system and explicitly provides foundations for colors, typography, grid and reusable components.

### Linear
Use as the strongest reference for:
- information density without visual noise
- sidebar/navigation hierarchy
- consistent headers and view controls
- keyboard-friendly product feel
- calm surfaces and strong hierarchy
- focused workflows

Linear's 2026 UI refresh specifically emphasizes easier scanning, consistent navigation/view controls and reduced visual noise.

### Stripe Dashboard
Use as the strongest reference for:
- business dashboard information architecture
- metric-first home
- list/detail workflows
- contextual actions
- filters
- tables
- charts
- focused workflows
- design tokens and component consistency

Stripe's design guidance explicitly recommends reusable components/patterns, consistent styling tokens and contextual views.

### Material / USWDS
Use as references for:
- accessibility
- focus states
- readable hierarchy
- restrained data visualization
- avoiding unnecessary chart complexity
- color-independent communication

USWDS guidance recommends common chart types, limiting each visualization to a central idea and avoiding excessive visual concepts.

## What we are NOT copying

We are not cloning Vercel, Linear, Stripe or Material.

We borrow proven principles and create a distinct **TikTok Shop Intelligence visual identity**.

## Design personality

- Calm
- Sharp
- Analytical
- Premium
- Trustworthy
- Action-oriented
- Minimal visual noise
- Information-dense but not overwhelming

## Core principle

**The dashboard should look simple because the system has done the complexity for the user.**
