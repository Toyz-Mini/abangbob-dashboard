# Responsive UX QA V1.7

Required viewport test bands:

- 360–390px mobile
- 768px tablet
- 1024px laptop
- 1280px desktop
- 1440px large desktop

Acceptance:
- no horizontal page overflow
- no clipped primary actions
- navigation remains discoverable
- diagnosis remains above secondary charts
- tables have an intentional mobile transformation
- charts remain readable
- filters remain usable
- touch targets remain practical

Do not simply scale desktop CSS down. Define intentional responsive layouts.
