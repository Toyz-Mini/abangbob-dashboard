# Data Visualization Specification V1.7

## Principle

One chart = one primary question.

USWDS guidance recommends familiar visualization types and limiting the number of concepts communicated at once. This product follows that principle.

## Preferred chart mapping

Trend:
- line chart

Comparison:
- horizontal bar

Funnel:
- staged funnel / connected conversion stages

Composition:
- stacked bar only when composition is the actual question

Distribution:
- histogram/box plot where useful

Relationship:
- scatter plot only for advanced analysis

Ranking:
- sorted horizontal bar/table

Anomaly:
- line chart with evidence markers

## Avoid

- 3D charts
- decorative gauges
- excessive donut charts
- radar charts for business decisions
- dual axes unless essential
- more than 5 categorical series
- chart junk

## Interaction

Hover is enhancement, never the only way to access data.

Charts must provide:
- text summary
- keyboard access where interactive
- accessible labels
- raw/tabular fallback for important data

## Data integrity

A chart must show:
- date range
- comparison period where relevant
- unit
- currency
- source/attribution context where relevant

Never visually imply causation from correlation alone.
