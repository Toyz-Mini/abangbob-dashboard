## Navigation hierarchy

Sidebar:
- workspace/shop switcher
- primary navigation
- recent/important analysis
- settings at bottom

Top bar:
- page title
- date range
- shop context
- global search/command
- user menu

## Overview is not a chart dump

Overview contains:
1. analysis freshness
2. headline business result
3. priority diagnosis
4. top changes
5. funnel health
6. product opportunities
7. ads/GMV Max status
8. action plan

## Insights

The Insights page is the core product surface.

It should answer:
- what changed
- confidence
- impact
- evidence
- action

## Details

Every important object supports:
List → Detail → Evidence → Action.

Examples:
Products → Product Detail → Evidence → Experiment
Diagnosis → Diagnosis Detail → Evidence → Action
Import → Import Detail → Validation → Mapping
